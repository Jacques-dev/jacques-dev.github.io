# jtellier.com

Page d'accueil du hub d'outils web, servie par GitHub Pages.

- En ligne : https://jtellier.com (et https://jacques-dev.github.io)
- Chaque outil vit dans son propre dépôt avec GitHub Pages activé et apparaît
  sous le domaine : par exemple [scenariste](https://github.com/Jacques-dev/scenariste)
  → https://jtellier.com/scenariste/

## Ajouter un outil au hub

1. Activer GitHub Pages sur le dépôt de l'outil (base Vite = `/nom-du-depot/`).
2. Ajouter une carte dans `index.html` pointant vers `/nom-du-depot/`.
